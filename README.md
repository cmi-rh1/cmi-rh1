# แดชบอร์ด CMI เขตสุขภาพที่ 1

หน้าเว็บสำหรับดูข้อมูลผู้ป่วยในของโรงพยาบาลในเขตสุขภาพที่ 1 เทียบกันภายในกลุ่มระดับบริการเดียวกัน ข้อมูลมาจาก CMI@MoPH (cmi.moph.go.th) อัปเดตอัตโนมัติเดือนละสองครั้ง

**เปิดใช้งานที่** https://cmi-rh1.github.io/cmi-rh1/

---

## ข้อมูลในหน้าเว็บมีอะไรบ้าง

ภาพรวมและการจัดอันดับของทุกโรงพยาบาลในเขต · CMI รายโรค (PDx 3 หลัก) เทียบกับค่ากลางของกลุ่ม · Adj AN ต่อ 10,000 ประชากร UC · ร้อยละผู้ป่วยในที่ AdjRW < 0.5 · สรุปจุดที่ควรทบทวนการสรุปเวชระเบียนรายโรงพยาบาล

นิยามและสูตรคำนวณทั้งหมดอยู่ท้ายหน้าเว็บ ในหัวข้อ **นิยามและวิธีคำนวณ**

---

## ไฟล์ในรีโปนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแดชบอร์ด ไม่มีข้อมูลอยู่ในตัว เปิดหน้าแล้วจึงไปอ่าน `data.json` |
| `data.json` | ข้อมูล PDx และ DRG ของทุกโรงพยาบาลในเขต ระบบเขียนทับให้ทุกรอบ **ไม่ต้องแก้เอง** |
| `scrape_cmi.py` | สคริปต์ดึงข้อมูลจาก cmi.moph.go.th |
| `hosname.csv` | ทะเบียนโรงพยาบาล ระดับบริการ จำนวนเตียง และประชากร UC |
| `server/` | สคริปต์ติดตั้งและสคริปต์ซิงค์ที่รันบนเซิร์ฟเวอร์ |

---

## ข้อมูลอัปเดตอย่างไร

เซิร์ฟเวอร์ภายในเครือข่ายกระทรวงสาธารณสุขรันสคริปต์ซิงค์ **ทุกวันที่ 1 และ 16 เวลา 08:00 น.** ดึงข้อมูลจาก cmi.moph.go.th แล้วส่ง `data.json` ชุดใหม่ขึ้นรีโปนี้ หน้าเว็บจะแสดงข้อมูลใหม่เองภายใน 1–2 นาที

ต้องใช้เซิร์ฟเวอร์ภายในประเทศเพราะ cmi.moph.go.th ไม่เปิดให้เข้าถึงจากต่างประเทศ จึงใช้ GitHub Actions แทนไม่ได้

ทุกรอบซิงค์จะตรวจข้อมูลก่อนเขียนทับ ถ้าดึงข้อมูลได้ไม่ครบตามเกณฑ์ หรือไฟล์ผิดรูปแบบ ระบบจะไม่แตะไฟล์เดิมและรอรอบถัดไป

---

## แก้ทะเบียนโรงพยาบาล

จำนวนเตียง ประชากร UC และระดับบริการ อยู่ในไฟล์ `hosname.csv` ซึ่งไม่ได้อยู่บนเว็บ CMI จึงไม่อัปเดตอัตโนมัติ

แก้ได้โดยกดที่ไฟล์ `hosname.csv` ในรีโปนี้ แล้วกดรูปดินสอเพื่อแก้ในเบราว์เซอร์ อย่าเปิดด้วย Excel แล้วบันทึกทับ เพราะภาษาไทยจะเพี้ยน

---

## ข้อจำกัดของข้อมูล

ข้อมูล PDx และ DRG เป็นยอดสะสมตั้งแต่ต้นปีงบประมาณ ไม่ใช่รายเดือน

โรงพยาบาลภูซางและโรงพยาบาลภูกามยาว จังหวัดพะเยา ยังไม่มีข้อมูล เพราะเว็บต้นทางตอบผิดพลาดทุกครั้งที่เรียกสองแห่งนี้ ข้อมูลจริงจึงครบ 101 จาก 103 แห่ง

ตัวเลขทั้งหมดอ้างอิงตามที่ CMI@MoPH เผยแพร่ ไม่ได้คำนวณใหม่จากฐานข้อมูลผู้ป่วยโดยตรง

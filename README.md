# แดชบอร์ด CMI เขตสุขภาพที่ 1 — ซิงค์อัตโนมัติด้วย GitHub Actions

เว็บนี้ประกอบด้วย 2 ส่วน
- `index.html` หน้าแดชบอร์ด (ไม่มีข้อมูลอยู่ในตัว)
- `data.json` ไฟล์ข้อมูลที่ GitHub ดึงจาก cmi.moph.go.th มาเขียนทับให้อัตโนมัติ

GitHub จะรันสคริปต์ `scrape_cmi.py` ทุกวันที่ 1 และ 16 เวลา 08:00 น. ไทย แล้ว commit `data.json` ใหม่
หน้าเว็บจะแสดงข้อมูลล่าสุดเองภายในไม่กี่นาที ไม่ต้องเปิดคอมพิวเตอร์

---

## ติดตั้งครั้งเดียว (ประมาณ 10 นาที)

### 1. สมัคร GitHub
เข้า https://github.com/signup ใช้อีเมลอะไรก็ได้ ฟรี

### 2. สร้าง repository
- กด **+** มุมขวาบน เลือก **New repository**
- Repository name: `cmi-rh1`
- เลือก **Public** (ถ้าเลือก Private จะใช้ GitHub Pages ฟรีไม่ได้)
- กด **Create repository**

### 3. อัปโหลดไฟล์ทั้งหมด
- ในหน้า repository กด **uploading an existing file**
- ลากไฟล์ทั้ง 4 ไฟล์นี้เข้าไป: `index.html`, `data.json`, `scrape_cmi.py`, `hosname.csv`
- กด **Commit changes**
- จากนั้นอัปโหลดโฟลเดอร์ `.github` ด้วย (ลากทั้งโฟลเดอร์เข้าไปในหน้าเดียวกัน ระบบจะเก็บโครงสร้าง `.github/workflows/sync.yml` ให้เอง)

> ถ้าลากโฟลเดอร์ `.github` ไม่ได้ ให้กด **Add file › Create new file** แล้วพิมพ์ชื่อไฟล์เป็น
> `.github/workflows/sync.yml` จากนั้นวางเนื้อหาไฟล์ลงไป

### 4. เปิด GitHub Pages
- แท็บ **Settings › Pages**
- Source: **Deploy from a branch**
- Branch: `main` / `/ (root)` แล้วกด **Save**
- รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/cmi-rh1/`

### 5. ทดสอบการดึงข้อมูล (ขั้นสำคัญ)
- แท็บ **Actions › Sync CMI data › Run workflow**
- รอประมาณ 5–8 นาที
- ถ้าขึ้นเครื่องหมายถูกสีเขียว = เครื่องของ GitHub เข้าเว็บกระทรวงได้ ใช้งานได้เลย
- ถ้าขั้นตอน **Check that cmi.moph.go.th is reachable** ล้มเหลว = GitHub เข้าเว็บกระทรวงไม่ได้
  ต้องเปลี่ยนไปดึงจากเครื่องในเครือข่ายไทยแทน (ดูหัวข้อ "ถ้า GitHub เข้าเว็บกระทรวงไม่ได้")

## การทำงานหลังติดตั้งเสร็จ

| เรื่อง | รายละเอียด |
|---|---|
| รอบดึงข้อมูล | วันที่ 1 และ 16 ของทุกเดือน เวลา 08:00 น. ไทย |
| เปลี่ยนรอบ | แก้บรรทัด `cron` ใน `.github/workflows/sync.yml` (เวลาเป็น UTC, ไทย = UTC+7) |
| ดึงเองทันที | Actions › Sync CMI data › Run workflow |
| ดูว่ารันสำเร็จไหม | แท็บ Actions จะมีประวัติทุกครั้ง กดดู log ได้ |
| ปีงบประมาณ | สคริปต์คิดให้เอง (ต.ค. ขึ้นปีงบใหม่) |
| ถ้าดึงได้ไม่ครบ | ถ้าได้ข้อมูลน้อยกว่า 80% ของ รพ. สคริปต์จะหยุดและไม่เขียนทับไฟล์เดิม ข้อมูลเก่าจึงไม่หาย |

GitHub อาจหยุดรันตามเวลาอัตโนมัติถ้า repository ไม่มีความเคลื่อนไหวเลย 60 วัน แต่การ commit ทุกรอบซิงค์นับเป็นความเคลื่อนไหวอยู่แล้ว

## ข้อมูลที่ต้องดูแลเอง

`hosname.csv` เก็บระดับบริการ จำนวนเตียง และ ปชก.UC ของแต่ละ รพ. มาจากไฟล์ M and E เขตสุขภาพที่ 1
ข้อมูลนี้ไม่ได้อยู่บนเว็บ CMI จึงไม่อัปเดตอัตโนมัติ ถ้าปีหน้ามีตัวเลข ปชก.UC ใหม่ ให้แก้ไฟล์นี้ใน GitHub ได้เลย (กดที่ไฟล์ แล้วกดรูปดินสอ)

---

## ถ้า GitHub เข้าเว็บกระทรวงไม่ได้

ใช้เครื่องในเครือข่ายไทยดึงแล้วส่งขึ้น GitHub แทน โดยรันสองคำสั่งนี้บนเครื่องที่มี Python และ Git

```
python scrape_cmi.py --region 1
git add data.json && git commit -m "sync" && git push
```

ทำเมื่อไรก็ได้ หน้าเว็บจะอัปเดตตาม ไม่ต้องพึ่ง Task Scheduler
